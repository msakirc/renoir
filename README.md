# Renoir — Image-output sanity check

> **Standalone.** Split from the [KutAI](https://github.com/msakirc/kutai) monorepo (`packages/renoir/`), where it is developed. It does not need the KutAI app; its test suite passes with only its declared dependencies installed.

## Purpose

Free image providers fail quietly: HTTP 200 with an HTML error page, an empty body,
a 1×1 pixel or a flat grey frame. Renoir is the image-side counterpart of
`dogru_mu_samet`: one cheap, deterministic check on generated bytes before anything
is written to disk.

**It does NOT** judge whether the image is good, matches the prompt or is on-brand —
it only rejects bytes that are not a usable image. No model calls, no network.

## Install

```bash
pip install "renoir @ git+https://github.com/msakirc/renoir.git"
```

Requires Python 3.10+. Sibling KutAI packages are installed from their own repositories.

## Quick start

```python
import io

from PIL import Image
from renoir import assess


def png(color, size=(64, 64)):
    buf = io.BytesIO()
    Image.new("RGB", size, color).save(buf, "PNG")
    return buf.getvalue()


print(assess(png((128, 0, 128))))
print(assess(png((128, 128, 128))))
print(assess(b"<html>rate limited</html>"))
```

## Public API

```python
from renoir import assess, ImageVerdict

v = assess(png_bytes)        # -> ImageVerdict(ok: bool, reason: str)
if not v.ok:
    print(v.reason)          # "empty" | "not_an_image" | "too_large" | "too_small" | "blank"
```

Rules: empty bytes → `empty`; Pillow cannot open/decode → `not_an_image`; more than
50 M pixels (checked from the header, before decoding) → `too_large`; a side under
16 px → `too_small`; every pixel identical **and** achromatic (black/white/grey) →
`blank`. A solid *coloured* image passes.

## Dependencies

- `pillow>=10`.

## Tests

```powershell
python -m pytest packages/renoir/tests
```

## In KutAI

[paintress](https://github.com/msakirc/paintress) runs `assess` on every generated image before writing it. Source: [`packages/renoir/`](https://github.com/msakirc/kutai/tree/main/packages/renoir) in the [KutAI monorepo](https://github.com/msakirc/kutai), where this package is developed.

## Status and limitations

- Standalone: it does not import the KutAI app, and its tests pass with only its declared dependencies.
- Version 0.1.0, part of a personal research project. Developed and tested on Windows 11 with Python 3.10; other platforms are untested.
- Catches broken or blank output only; it does not score aesthetics or prompt adherence.

## Türkçe

### Amaç

Ücretsiz görüntü sağlayıcıları sessizce bozulur: HTML hata sayfasıyla HTTP 200, boş
gövde, 1×1 piksel ya da düz gri kare. Renoir, `dogru_mu_samet`'in görüntü tarafındaki
karşılığıdır: diske bir şey yazılmadan önce üretilen baytlar üzerinde tek, ucuz ve
belirlenimci bir denetim.

Görüntünün iyi olup olmadığını, isteme uyup uymadığını **değerlendirmez** — yalnızca
kullanılabilir görüntü olmayan baytları reddeder. Model çağrısı ve ağ erişimi yoktur.

### Kurulum

```bash
pip install "renoir @ git+https://github.com/msakirc/renoir.git"
```

Python 3.10+ gerekir. Kardeş KutAI paketleri kendi depolarından kurulur.
